Let C be the category
0 -> 1,    0 -> 2,
and let D be obtained from C by adjoining an object 3 and arrows
1 -> 3,    2 -> 3
with the evident composites. Let j : C -> D be the inclusion.

Define F : C -> Set by

F(0) = {1,2,3,4,5,6},
F(1) = {b_1,b_2,b_3,b_4},
F(2) = {c_1,c_2,c_3,c_4,c_5},

where the two structure maps send 1,...,6, respectively, to

(b_1,b_1,b_2,b_3,b_3,b_4)

and

(c_1,c_2,c_2,c_3,c_4,c_4).

How many elements does
(Lan_j F)(3)
have?

Give your final answer as a single integer. Your response must contain nothing else; any additional text will be counted as incorrect.
