QUESTION
========

In Set, let
X -> Z <- Y
with Z = {0,1}. Suppose
|f^{-1}(0)| = 2, |f^{-1}(1)| = 1,
and
|g^{-1}(0)| = 3, |g^{-1}(1)| = 1.

How many elements does the pullback X x_Z Y have?

Give your final answer as a single integer. Your response must contain nothing else; any additional text will be counted as incorrect.


REASONING
=========


We are given a diagram: X -> Z <- Y, with Z = {0,1}. So Z has two elements: 0 and 1. f: X -> Z and g: Y -> Z are functions. We are given the sizes of fibers:
|f^{-1}(0)| = 2
|f^{-1}(1)| = 1
|g^{-1}(0)| = 3
|g^{-1}(1)| = 1

We need to find the number of elements in the pullback X ×_Z Y. The pullback (fiber product) is the set of pairs (x,y) ∈ X × Y such that f(x) = g(y). So it's the set of all pairs with the same Z-value.

We can compute the total number of pairs with f(x)=g(y)=0 plus pairs with f(x)=g(y)=1.

Number of elements in f^{-1}(0) = 2, g^{-1}(0) = 3 => number of pairs (x,y) with f(x)=0 and g(y)=0 = 2 * 3 = 6.
Number of elements in f^{-1}(1) = 1, g^{-1}(1) = 1 => number of pairs with f(x)=1 and g(y)=1 = 1 * 1 = 1.
Total pullback = 6 + 1 = 7.

Thus the answer is 7.
